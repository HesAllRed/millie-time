# Millie Time

Millie's weekly photo recap!

## Running it

```bash
node tools/dev-server.mjs
```

Then <http://localhost:5173>. Add `#debug` for the on-device diagnostics screen.

The three lines in the top right open **options** — the colours the app wears —
and **etc**, which throws confetti at your thumb. The choice is remembered
separately from the week, so starting a new one never resets it.

Five of the schemes are a fixed palette; two of them move — *Rainbow* turns the
whole wheel, *Aurora* drifts from green to violet and back — and below them two
sliders mix your own, hue and how much of it. All three roads lead to the same
`spectrum()` in `public/js/theme.js`: one hue in, a whole palette out, with every
lightness fixed. That last part is why the sliders can be handed over without a
warning — there is no hue and no setting of them that makes the app unreadable,
and there is a test that sweeps the wheel to prove it. The moving two are
sampled a dozen times a second, and hold still under Reduce Motion.

```bash
npm test
```

That includes an end-to-end pass over the share order: it drives real Chromium
over the DevTools protocol, picks generated photos into the real file input, and
checks the exact array handed to `navigator.share()`. No dependencies — it uses
whatever Chrome or Edge is already installed, and skips itself if there is none.
Set `CHROME_PATH` to point it somewhere specific.

What it can't cover is what Messages does with the payload afterwards. That is on
the far side of the OS, so `#debug` has an **order test**: it sends six numbered
photos whose filename, capture date and file timestamp each say a *different*
order. Whichever order they land in names the rule that receiving app actually
uses. See `public/js/probe.js`.

## Layout

```
public/                    ← everything Cloudflare serves
  index.html  app.css  sw.js  manifest.webmanifest  _headers
  fonts/                   self-hosted woff2, so it works with no signal
  icons/                   generated by tools/icon-maker.html
  js/
    config.js              ← every personal string lives here
    theme.js               the colour schemes — still, moving, and mixed by hand
    state.js               one store; views read, never mutate
    dates.js  exif.js  compose.js     pure, tested
    media.js  print.js  share.js
    resize.js              re-encodes a week to a common weight, so it arrives in order
    probe.js               the on-device order test
    ui.js  menu.js  confetti.js
    views/                 intake · sort · deck · send · debug
test/                      node:test, including the end-to-end share order
tools/                     dev server, icon generator
  harness/                 drives Chromium over CDP, no dependencies
```
