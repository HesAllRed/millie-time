# Millie Time

Millie's weekly photo recap!

## Running it

```bash
node tools/dev-server.mjs
```

Then <http://localhost:5173>. Add `#debug` for the on-device diagnostics screen.

```bash
npm test
```

## Layout

```
public/                    ← everything Cloudflare serves
  index.html  app.css  sw.js  manifest.webmanifest  _headers
  fonts/                   self-hosted woff2, so it works with no signal
  icons/                   generated by tools/icon-maker.html
  js/
    config.js              ← every personal string lives here
    state.js               one store; views read, never mutate
    dates.js  exif.js  compose.js     pure, tested
    media.js  print.js  share.js
    ui.js
    views/                 intake · sort · deck · send · debug
test/                      node:test
tools/                     dev server, icon generator
```
